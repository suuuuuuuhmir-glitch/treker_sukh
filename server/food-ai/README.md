# Калории по фото еды

Человек фотографирует тарелку, трекер присылает фото сюда, функция
спрашивает ИИ и возвращает продукты с граммами, калориями и БЖУ.
Человек видит список и сам решает, записать его или нет.

Ключ от ИИ лежит только в этой функции. В приложение его класть нельзя:
код приложения открыт, ключ украдут и потратят деньги.

Кнопка «Посчитать по фото» появляется в «Питании», когда в `tracker.html`
задана ссылка на функцию:

```js
const FOOD_AI=window.MF_FOOD_AI||'https://functions.yandexcloud.net/…';
```

Считать по фото могут только те, кто вошёл в аккаунт (так чужие не смогут
тратить наш лимит). Токен аккаунта трекер кладёт в тело запроса (поле `token`),
а не в заголовок `Authorization`: Яндекс вырезает этот заголовок до того,
как запрос попадёт в функцию. Запрос уходит как `text/plain`, поэтому браузер
не делает лишний запрос OPTIONS. Лимит по умолчанию: 15 фото в день на человека
и 500 в день всего. Если ИИ не ответил, попытка не считается.

## Какую модель выбрать

| | Яндекс (Qwen 3.6) | GigaChat 2 Max |
|---|---|---|
| Одно фото | ~0,4 ₽ | ~1,5 ₽ (платный пакет) |
| Бесплатно | стартовый грант новым аккаунтам Яндекс Облака | большой бесплатный лимит на год, но только для личного некоммерческого использования |
| Много людей сразу | да | физлицу дают один запрос за раз |
| Для всех пользователей | да | нужен платный пакет |

План: проверить обе на своих фото, для всех включить ту, что точнее
(скорее всего Яндекс, он дешевле). Переключение одной переменной `PROVIDER`.

## Настройка в Яндекс Облаке (минут 15)

1. Открой [console.yandex.cloud](https://console.yandex.cloud) и войди
   Яндекс ID. Если платёжного аккаунта ещё нет, создай его: нужна карта,
   новым аккаунтам обычно дают стартовый грант. Без платёжного аккаунта
   ИИ не отвечает.
2. Запомни **идентификатор каталога**: он вида `b1g…`, виден вверху
   страницы каталога (обычно каталог `default`).
3. **Сервисный аккаунт.** Слева «Identity and Access Management» →
   «Сервисные аккаунты» → «Создать». Имя `mishkafit-food`, роль
   `ai.languageModels.user`. Создать.
4. **Функция.** Слева «Cloud Functions» → «Создать функцию», имя
   `mishkafit-food`. Открой её → «Редактор»:
   - Среда выполнения: **Node.js 22**.
   - Способ: «ZIP-архив», загрузи `mishkafit-food-ai.zip`
     (или «Редактор кода»: создай файл `index.js` и вставь код из этой папки).
   - Точка входа: `index.handler`.
   - Таймаут: **60** секунд, память: **256 МБ**.
   - Сервисный аккаунт: `mishkafit-food`.
   - Переменные окружения:
     - `PROVIDER` = `yandex`
     - `YANDEX_FOLDER` = идентификатор каталога из шага 2
     - `FIREBASE_API_KEY` = `AIzaSyAdJ9VHSAmqvJeErawH5JceDTpqBLO3g0g`
       (тот же публичный ключ, что уже стоит в трекере)
   - «Сохранить изменения».
5. Вкладка «Обзор» → включи **«Публичная функция»**. Скопируй ссылку
   вида `https://functions.yandexcloud.net/d4e…`.
6. Пришли эту ссылку Claude: он вставит её в трекер.

Проверка: открой ссылку в браузере. Должно показать
`{"ok":true,"provider":"yandex"}`.

## Как обновить код функции

Когда в этой папке меняется `index.js`, функцию надо обновить:

1. Открой функцию `mishkafit-food` → вкладка «Редактор».
2. Способ: «ZIP-архив», загрузи новый `mishkafit-food-ai.zip`.
3. Проверь, что остальное подставилось из прошлой версии: Node.js 22,
   `index.handler`, таймаут 60, сервисный аккаунт и переменные окружения.
4. «Сохранить изменения». Ссылка на функцию не меняется.

## Тест на GigaChat (бесплатно, только для себя)

1. Открой [developers.sber.ru/studio](https://developers.sber.ru/studio),
   войди через Сбер ID, создай проект **GigaChat API** (тариф для физлиц,
   Freemium). В настройках проекта нажми «Получить ключ» и скопируй
   **ключ авторизации** (длинная строка, заканчивается на `==`).
2. Скачай сертификат Минцифры:
   [russian_trusted_root_ca_pem.crt](https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt).
   Без него Сбер не даёт защищённое соединение.
3. В редакторе функции создай файл `russian_trusted_root_ca.pem`
   и вставь туда содержимое скачанного файла (открывается любым
   текстовым редактором, начинается с `-----BEGIN CERTIFICATE-----`).
4. Поменяй переменные: `PROVIDER` = `gigachat`,
   добавь `GIGA_AUTH_KEY` = ключ из шага 1. Сохрани.
5. Сфоткай еду в трекере и сравни с Яндексом на тех же фото.

По правилам Сбера бесплатный GigaChat можно использовать только лично.
Перед тем как включать его для всех, нужен платный пакет.

## Все переменные

| Переменная | Что это | По умолчанию |
|---|---|---|
| `PROVIDER` | `yandex` или `gigachat` | `yandex` |
| `YANDEX_FOLDER` | идентификатор каталога | — |
| `YANDEX_API_KEY` | API-ключ, если у функции нет сервисного аккаунта | — |
| `YANDEX_MODEL` | модель с картинками | `qwen3.6-35b-a3b` |
| `GIGA_AUTH_KEY` | ключ авторизации GigaChat | — |
| `GIGA_SCOPE` | `GIGACHAT_API_PERS` (физлицо) или `GIGACHAT_API_B2B` | `GIGACHAT_API_PERS` |
| `GIGA_MODEL` | модель | `GigaChat-2-Max` |
| `GIGA_BASE` | адрес API, если Сбер его сменит | `https://gigachat.devices.sberbank.ru/api/v1` |
| `FIREBASE_API_KEY` | пускать только вошедших в аккаунт; без неё функция открыта всем | — |
| `DAILY_LIMIT` | фото в день на человека | `15` |
| `TOTAL_LIMIT` | фото в день всего | `500` |
| `ALLOW_ORIGINS` | сайты, с которых можно звать функцию | mishkafit.ru и GitHub Pages |

Лимиты считаются в памяти функции, поэтому они примерные: если Облако
запустит несколько копий функции, у каждой свой счётчик. Для начала
этого хватает; когда людей станет много, счётчик можно перенести в базу.
Фото нигде не сохраняются: GigaChat-версия удаляет файл у Сбера сразу после ответа.
